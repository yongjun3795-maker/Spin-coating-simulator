# 스핀코팅 시뮬레이터 (EBP 모델)

포토레지스트 도포 공정을 **Emslie–Bonner–Peck 모델**로 푸는 웹 시뮬레이터.
회전수·점도·증발 속도를 바꿔가며 막이 어떻게 얇아지고, 언제 굳고,
최종 두께가 무엇으로 정해지는지 본다.

성균관대 화학공학부 유체역학 텀 프로젝트에서 시작해,
**공정 엔지니어가 실제로 보는 그래프(스핀 커브)와 모델 검증**을 붙여 다시 만들었다.

```bash
npm install
npm run dev
```

---

## 무엇을 푸나

축대칭 얇은막 윤활 근사에서 액막 두께 h(r, t) 는 이렇게 움직인다.

```
∂h/∂t = −(1/r)·∂(r·q)/∂r − E ,      q = ρω²r·h³/(3η)
```

- 첫 항 — 원심력이 액을 바깥으로 밀어내는 배출
- 둘째 항 — 용매 증발

**h 가 반경 방향으로 균일하면** 발산항이 r 에 무관해져 EBP 의 잘 알려진 꼴이 된다.

```
dh/dt = −2ρω²h³/(3η) − E
```

점도는 Meyerhofer 의 농축 모형: `η(h) = η₀·(h₀/h)ⁿ`.
용매가 날아가 막이 얇아질수록 점도가 오른다.

## 네 가지 탭

### 1. 스핀 커브 — h vs ω

**공정에서 실제로 쓰는 그래프다.** 회전수를 500 → 8000 rpm 로 훑어
겔화 시점의 두께를 뽑고 로그-로그로 회귀해 `h ∝ ω^p` 의 p 를 낸다.

여기에 이 프로젝트의 제일 재미있는 지점이 있다. 겔화 조건

```
2ρω²h^(3+n) / (3η₀h₀ⁿ) = E
```

를 h 에 대해 풀면 **해석적으로 지수가 나온다.**

```
h_gel ∝ ω^( −2/(3+n) )
```

수치해를 이 예측과 대조하면:

| n | 시뮬레이션 p | 이론 −2/(3+n) | 차이 |
|---|---|---|---|
| 0 | −0.6674 | −0.6667 | 0.0007 |
| **1** | **−0.5003** | **−0.5000** | 0.0003 |
| 2 | −0.4002 | −0.4000 | 0.0002 |
| 3.5 | −0.3079 | −0.3077 | 0.0002 |
| 5 | −0.2500 | −0.2500 | 0.00004 |

> **n = 1 에서 정확히 −1/2 가 나온다.**
> 스핀코팅의 잘 알려진 실험 경험식 h ∝ ω<sup>−1/2</sup> 가
> 이 모델 안에서 **어떤 조건에서 성립하는지**를 특정해준다.

그리고 **증발을 0 으로 두면 이 관계가 무너진다.** 겔화가 없으면 막이 계속 얇아져
최종 두께라는 게 성립하지 않기 때문이다. 즉 −1/2 승은 원심력만으로 나오는 게 아니라
**용매 증발이 있어야 나온다.**

### 2. h(t) — 두께

시간에 따른 두께. 겔화 시각에 세로선이 선다.
`E = 0`, `n = 0` 으로 두면 해석해

```
h(t) = h₀ / √(1 + 4ρω²h₀²t / 3η₀)
```

가 점선으로 겹쳐 그려진다. **현재 적분기의 상대오차 0.063 %** — 이 겹침이 곧 솔버 검증이다.

### 3. h(r) — 평탄화

⚠️ **EBP 의 유명한 결과: 균일한 막은 균일하게 유지된다.**
h 가 r 에 무관하면 발산항도 r 에 무관해지기 때문이다.

그래서 균일한 초기조건으로 이 솔버를 돌리면 남는 "불균일도"는 물리가 아니라
**수치 오차**다. 실제로 `초기 중앙 과잉 = 0 %` 로 두면 **0.000 %** 가 나온다 — 솔버 검증.

정작 보고 싶은 건 반대쪽이다. **불균일하게 떨어뜨린 액이 스스로 평탄해지는 과정.**
슬라이더로 중앙을 두껍게 주면(기본 35 %) 두꺼운 곳이 `h³` 로 훨씬 빨리 빠져나가
**10 초 만에 불균일도가 0.002 % 까지 내려간다.** 이것이 스핀코팅이 평탄화 공정인 이유다.

### 4. η(t) — 점도

`η/η₀` 가 시간에 따라 어떻게 오르는지. 겔화가 왜 생기는지가 여기서 보인다.

## 수치 기법

**적응 스텝 적분.** 배출항이 `h³` 이라 초기 `dh/dt` 가 조건에 따라 3~4 자릿수까지 벌어진다.
8000 rpm · 1 mPa·s · 50 µm 에서는 고정 `dt = 1e-4` 가 한 스텝에 6 µm 를 깎아 해가 무너진다.
그래서 **매 스텝 h 의 0.5 % 만 움직이도록 dt 를 잡는다.**
기본 조건에서 스텝 수가 **1,200,000 → 278** 로 줄면서 정확도는 올라갔다.

**차트 점은 따로 솎아낸다.** 적분 정확도와 차트가 받는 점의 개수는 별개다.

**보존형 유한체적.** 반경 방향은 면(face)에서 `r·q` 를 계산하고 셀에서 발산을 취한다.
비보존형 차분은 질량을 흘려서 균일 초기조건이 균일하게 유지되지 않는다 —
그러면 위의 검증 자체가 성립하지 않는다.

**겔화에서 적분을 멈춘다.** 원심 배출이 증발 아래로 내려가면 고체 골격이 남아
막이 더 얇아지지 않는다. 이걸 빠뜨리면 **최종 두께가 조건과 무관하게 바닥값으로 수렴해
스핀 커브가 통째로 무의미해진다.**

**Re 감시.** 축소 레이놀즈수 `ρωh₀²/η₀` 를 항상 표시한다.
`≪ 1` 이 아니면 윤활 근사가 서지 않으므로 결과를 믿으면 안 된다.

## 구조

```
src/physics.js   솔버 — solveEBP · solveRadial · spinCurve · reducedRe
src/App.jsx      UI — 슬라이더, 지표, 4개 차트
```

물리를 UI 에서 분리해두어 `physics.js` 는 브라우저 없이 Node 에서 바로 검증할 수 있다.

```js
import { spinCurve } from "./src/physics.js";
const s = spinCurve({ omega_rpm: 3000, eta0_mPas: 10, h0_um: 10,
                      E_nm_s: 50, n: 1, rho: 1100 });
console.log(s.exponent, s.theory);   // -0.5003  -0.5
```
